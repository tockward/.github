# Tockward

**Know when your cron jobs, scripts and devices go silent.**

Your job pings a URL when it runs. If the ping doesn't arrive on time,
Tockward alerts you by email or Telegram.

```sh
curl -fsS https://ping.tockward.com/<your-id>
```

- Cron jobs, backups, scheduled tasks, CI pipelines
- IoT and field devices that should check in regularly
- Status pages, reports, team roles, API
- Native macOS menu bar app
